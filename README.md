## 🤖 Airline Compensation Calculator – Automated Claim Processing System
### 📘 Overview

Airline Compensation Calculator is an RPA-powered automation solution developed to streamline passenger compensation processing for airline service disruptions.

The system validates passenger details, checks compensation eligibility based on airline policies, performs automated compensation calculations, and sends results directly to customers through email notifications.

The automation reduces repetitive manual calculations, improves processing accuracy, and enhances customer service efficiency.

### 🧩 Problem Statement

Airline customer support teams often handle large numbers of compensation requests manually, making the process time-consuming and error-prone.

Traditional workflows can:
1. Delay compensation processing
2. Increase manual verification effort
3. Cause calculation inconsistencies
4. Reduce customer response efficiency
5. Create difficulty in handling bulk requests

This project solves these challenges using RPA-driven automation and rule-based compensation processing.

---

### 🚀 Key Features
#### 1. PNR Validation System

Validates passenger booking details using PNR information from Excel or Google Sheets.

#### 2. Automated Compensation Calculation

Calculates compensation amounts automatically based on predefined airline eligibility policies and conditions.

#### 3. Rule-Based Eligibility Checking

Verifies passenger eligibility for compensation before processing calculations.

#### 4. Excel & Google Sheets Integration

Reads and processes passenger data directly from structured spreadsheets.

#### 5. Automated Email Communication

Sends compensation calculation results and status updates directly to customers through automated email workflows.

---

### ⚙️ Workflow Architecture
1. Read passenger data from Email and Excel/Google Sheets(Database)
2. Validate passenger PNR details
3. Check airline compensation eligibility rules
4. Calculate compensation amount automatically
5. Generate result summary
6. Send automated email notification to customer
7. Store processed records for tracking
